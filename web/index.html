2-Player Local Wi-Fi Setup

Strictly 2 human players cooperating simultaneously over a local network. No internet connection required.

1

Connect Wi-Fi

Connect both devices to the same local Wi-Fi router or physical mobile hotspot.

2

Host Server

Device 1 taps Host Server, picks Linh, selects a specialization, and taps Ready.

3

Join Shift

Device 2 enters Device 1's local IP, taps Join LAN, selects Jiwon, and taps Ready.

4

Start Shift

Host taps Start Shift once both chefs are locked in. Manage orders and maintain Kitchen Flow!
