2-Player Local Wi-Fi Setup

Strictly 2 human players cooperating simultaneously over a local network. Zero cloud latency, zero accounts.

1

Connect Wi-Fi

Connect both devices (PC or Android) to the same local Wi-Fi router or physical mobile hotspot.

2

Host Shift

Chef 1 names the kitchen room and taps Host. The room screen shows the host's Wi-Fi IP.

3

Auto-Discover

Chef 2 opens Join; the game scans your Wi-Fi for kitchens • tap to join (or type the host's Wi-Fi IP).

4

Start Cooking

Both chefs press READY, then the host taps Start. Pass ingredients across the counter and satisfy the rush!
